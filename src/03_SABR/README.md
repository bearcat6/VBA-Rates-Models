# 03_SABR

Normal SABR によるスマイル補間、密度計算、分位点計算を管理するためのモジュールです。

この領域では、スワップションやキャップなどの金利オプション・ボラティリティを対象に、ストライク方向のスマイルを表現し、価格曲線、密度関数、分位点を計算できる構成を目指します。

## 想定する内容

```text
classes/
  clsSABRNormal.cls
  clsSABRCalibrator.cls
  clsSmileSlice.cls
modules/
  mdl_SABRMath.bas
  mdl_SABRDensity.bas
```

## 初期スコープ

- Normal SABR を対象とします。
- `beta = 0` を基本前提とします。
- `alpha`、`rho`、`nu` のパラメータ検証を行います。
- 市場ボラティリティへのスマイル・フィットを行います。
- ストライク別価格から密度関数を計算します。
- 分位点、または指定ストライクに対応する累積確率を計算します。

## 依存関係

このモジュールは、原則として共通部品のみに依存します。

```text
src/00_Common
```

割引カーブ、OISスワップ、Hull-White、CMSスプレッド関連のモジュールには直接依存しない方針とします。

## 設計上の考え方

- SABRはCMS専用ではなく、金利分布、ストレスカーブ、リスク分析にも使える独立モジュールとして管理します。
- スマイル補間、キャリブレーション、密度計算、分位点計算は役割を分けます。
- Excelシート入出力に直接依存せず、VBAクラス・関数として再利用できる形を優先します。
- パラメータ範囲、異常値、補間失敗時のエラー処理を明示的に扱います。
