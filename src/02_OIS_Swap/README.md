# 02_OIS_Swap

OISスワップの商品表現、キャッシュフロー生成、評価ロジックを管理するためのモジュールです。

この領域では、JPY TONA/OIS 割引カーブを前提として、固定レグ・変動レグのキャッシュフロー生成、PV、NPV、パーレート計算などを整理します。

## 想定する内容

```text
classes/
  clsOISSwap.cls
  clsOISLeg.cls
  clsCashflow.cls
modules/
  mdl_OISSwapPricer.bas
```

## 依存関係

このモジュールは、以下の共通部品・カーブ部品に依存してよいものとします。

```text
src/00_Common
src/01_Discount_Curve
```

一方で、SABR、Hull-White、CMSスプレッド関連のモジュールには依存しない方針とします。

## 設計上の考え方

- OISスワップの商品条件と、割引カーブ構築ロジックは分離します。
- キャッシュフロー生成と評価計算を分けて、テストしやすい構成にします。
- Excelシートから直接値を読む処理は、できるだけ上位の実行用モジュールに寄せます。
- クラスや関数は、将来的に他の商品評価やストレス計算から再利用できるようにします。
