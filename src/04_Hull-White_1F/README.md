# 04_Hull-White_1F

1ファクター Hull-White モデルのキャリブレーション、モンテカルロシミュレーション、将来金利カーブ生成を管理するためのモジュールです。

この領域では、OIS割引カーブとスワップション・ボラティリティなどを入力として、Hull-White 1F モデルのパラメータを決定し、将来時点の金利カーブをシミュレーションする構成を目指します。

## 想定する内容

```text
classes/
  clsHullWhite1F.cls
  clsHWCalibrator.cls
  clsHWSimulator.cls
  clsVolSurface.cls
modules/
  mdl_HullWhiteMath.bas
  mdl_HullWhiteWorkflow.bas
```

## 主な役割

- 初期OIS割引カーブから瞬間フォワード、ゼロレート、割引係数を参照します。
- スワップション・ボラティリティなどに対して Hull-White 1F のパラメータをキャリブレーションします。
- 平均回帰速度、ボラティリティ、時間依存ドリフト項を扱います。
- 短期金利パスをモンテカルロシミュレーションします。
- 1年後などの将来時点における金利カーブを複数生成します。
- 生成したカーブから分位点カーブ、ストレスカーブ、リスク分析用シナリオを作成できるようにします。

## 依存関係

このモジュールは、以下の共通部品・カーブ部品に依存してよいものとします。

```text
src/00_Common
src/01_Discount_Curve
```

SABR、CMSスプレッド、OISスワップの商品評価モジュールには、原則として直接依存しない方針とします。

## 設計上の考え方

- モデル本体、キャリブレーション、シミュレーション、Excel上の実行フローを分離します。
- モデルクラスは、Excelのワークシート名やセル範囲に直接依存しないようにします。
- 乱数生成は、必要に応じて `06_RandomNumber` の共通ロジックを利用できる構成を想定します。
- キャリブレーション対象、補間方法、境界条件、エラー処理を明示的に扱います。
- 将来カーブ生成では、シミュレーション結果を後続の分位点分析やストレスシナリオ作成に使いやすい形で返します。

## 注意事項

Hull-White 1F は金利カーブ全体の動きを1つのファクターで表現するモデルです。

実務利用する場合は、キャリブレーション対象、ボラティリティ入力、時間刻み、乱数品質、カーブ再構築方法、モデル限界を別途確認する必要があります。
