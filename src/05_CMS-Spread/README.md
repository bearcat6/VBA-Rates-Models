# 05_CMS-Spread

CMSおよびCMSスプレッド評価に関連するロジックを管理するためのモジュールです。

この領域では、将来的なCMSスプレッド・スワップ評価を見据えて、スワップション・ボラティリティ処理、CMSレグ、CMSスプレッドレグ、評価補助関数などを整理します。

## 現在の位置づけ

現時点では、CMS関連評価に必要となるスワップション・ボラティリティの取り扱いを中心に管理します。

将来的には、CMSレートのコンベクシティ調整、CMSスプレッドの評価、スマイルを考慮した近似評価、シナリオ分析への拡張を想定します。

## 想定する内容

```text
classes/
  clsATMSwaptionVol.cls
  clsCMSSpreadTrade.cls
  clsCMSLeg.cls
  clsCMSSpreadLeg.cls
modules/
  mdl_CMSVolUtils.bas
  mdl_CMSSpreadPricer.bas
```

## 主な役割

- ATMスワップション・ボラティリティを管理します。
- CMS評価に必要なボラティリティ補間・参照ロジックを整理します。
- CMSレグ、CMSスプレッドレグの商品条件を表現します。
- CMSスプレッド・スワップの評価ロジックを段階的に追加します。
- 必要に応じてSABRスマイルや密度計算と連携します。

## 依存関係

このモジュールは、以下のモジュールに依存してよいものとします。

```text
src/00_Common
src/01_Discount_Curve
src/03_SABR
```

OISスワップの構築ロジックやアニュイティ計算を明示的に再利用する場合のみ、`src/02_OIS_Swap` への依存を追加する方針とします。

## 設計上の考え方

- CMSスプレッド評価固有の処理と、汎用的なボラティリティ処理を分けます。
- SABRはこのモジュールに閉じ込めず、`03_SABR` の独立した機能として利用します。
- 商品条件、ボラティリティ参照、評価計算、Excel上の実行フローを分離します。
- 将来的にTONAベースのCMSスプレッド・スワップ評価へ拡張しやすい構成にします。
- 実務利用時は、ボラティリティ入力、補間方法、コンベクシティ調整、近似式の妥当性を別途確認します。
