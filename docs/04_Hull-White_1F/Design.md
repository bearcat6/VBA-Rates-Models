# Hull-White 1F設計

## 目的

`04_Hull-White_1F` は、1ファクター Hull-White モデル、キャリブレーション補助、モンテカルロシミュレーションの設計を扱うドキュメント領域です。

主な目的は、割引カーブとスワップション・ボラティリティを入力として、将来時点のJPY金利カーブを生成し、分位点カーブやストレスカーブを作成することです。

## モデル

対象とする基本モデルは以下です。

```text
dr(t) = { theta(t) - a r(t) } dt + sigma dW(t)
```

実装上は、以下の shifted short-rate representation を利用します。

```text
r(t) = phi(t) + x(t)
dx(t) = -a x(t) dt + sigma dW(t)
```

`theta(t)` は直接入力するパラメータとしては扱いません。

初期割引カーブと整合するように、`phi(t)` または初期フォワードカーブを通じて暗黙的に扱います。

## 役割

このモジュールの主な役割は以下のとおりです。

- Hull-White 1F のパラメータを保持する。
- 割引カーブを time-based interface 経由で利用する。
- 初期スコープでは、`sigma` をボラティリティデータへフィットする。
- 将来時点の短期金利ファクターをシミュレーションする。
- 将来時点の割引カーブ、ゼロレートカーブ、フォワードカーブを生成する。
- シミュレーション結果から、分位点カーブやストレスカーブを作成する。

| クラス | 役割 |

| モジュール | 役割 |

| `mdl_HullWhiteMath` | Hull-Whiteモデルに関する数値計算・補助関数 |
| `mdl_HullWhiteWorkflow` | Excel上での実行フロー、入出力、薄い orchestration 層 |

## 必要なカーブインターフェース

Hull-White側では、カーブオブジェクトが以下のメソッドを持つことを前提とします。

```vb
DF_T(T)
ForwardRate_T(T1, T2)
InstantaneousForward(T)
```

ここで、`T`、`T1`、`T2` は評価日からの年数です。

Hull-Whiteモデル本体は、OISカーブの具体的な構築方法には依存しない設計とします。

## 初期キャリブレーション範囲

初期実装では、以下の簡易スコープとします。

- 平均回帰 `a` は外部から固定値として与える。
- ボラティリティ `sigma` を ATM Normal Swaption Volatility にフィットする。
- 厳密なスワップション評価式や、複数パラメータの同時最適化は将来拡張とする。

## 依存関係のルール

許容する依存関係：

```text
04_hull_white_1f -> 01_discount_curve
04_hull_white_1f -> common
```

避ける依存関係：

```text
04_hull_white_1f -> 02_ois_swap
04_hull_white_1f -> 05_cms_spread
```

## 設計上の注意点

Excelシートからの読み込みや、シートへの出力は、モデル本体のクラスには入れません。

以下のように責務を分けます。

```text
clsHullWhite1F       : モデル本体
clsHWCalibrator      : キャリブレーション
clsHWSimulator       : シミュレーション
mdl_HullWhiteMath    : 数値計算
mdl_HullWhiteWorkflow: Excel上での実行フロー
```

モデルクラスがシート名やセル範囲に直接依存すると、後からテストや再利用がしにくくなるため、Excel I/O は workflow 側に寄せます。

## リスク管理での利用イメージ

想定する利用の流れは以下です。

```text
1. JPY OIS割引カーブを作成する
2. スワップション・ボラティリティを読み込む
3. 平均回帰 a を設定する
4. sigma をボラティリティへフィットする
5. 将来時点、たとえば1年後の金利カーブを多数シミュレーションする
6. 年限ごとに分位点を計算する
7. 分位点カーブやストレスカーブを作成する
```

このモジュールは、将来金利カーブの分布を作るためのモデルです。

一方で、SABRによる密度・分位点計算とは考え方が異なるため、両者の用途や説明は分けて管理します。
