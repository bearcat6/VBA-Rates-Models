# SABR設計

## 目的

`03_SABR` は、Normal SABR によるスマイル・モデリングを扱うドキュメント領域です。

初期対象は、金利オプション市場で観測される Normal Volatility を、Expiry、Tenor、Strike または Moneyness ごとに扱うケースです。

SABRはCMS評価専用ではなく、スワップション・スマイルの補間、密度関数の推定、分位点計算、ストレスシナリオ作成にも利用できるため、独立したモジュールとして管理します。

## 役割

このモジュールの主な役割は以下のとおりです。

- SABRパラメータを保持する。
- パラメータ範囲を検証する。
- 観測されたNormal Volatilityに対してSABRパラメータをフィットする。
- Normal Volatilityからオプション価格を計算する。
- 必要に応じて、ストライク方向の価格曲線を平滑化する。
- オプション価格からインプライド密度を計算する。
- ストライクから分位点を求める。
- 分位点からストライクを逆算する。

## 初期モデル範囲

初期実装では以下を対象とします。

- Normal SABR
- `beta = 0` 固定
- パラメータは以下の3つ
  - `alpha`
  - `rho`
  - `nu`

## 候補クラス

| クラス | 役割 |
|---|---|
| `clsSABRNormal` | Normal SABRモデル本体とボラティリティ関数 |
| `clsSABRCalibrator` | ストライク別ボラティリティからSABRパラメータを推定するクラス |
| `clsSmileSlice` | 1つの Expiry × Tenor に対応するスマイル断面を表すクラス |

## 候補標準モジュール

| モジュール | 役割 |
|---|---|
| `mdl_SABRMath` | SABR式および関連する補助関数 |
| `mdl_SABRDensity` | 密度計算、分位点計算、逆算処理 |
| `mdl_Bachelier` | Normalモデルによるオプション価格計算。広く使う場合は `common` に置くことも検討する |

## 依存関係のルール

許容する依存関係：

```text
03_sabr -> common
```

避ける依存関係：

```text
03_sabr -> 05_cms_spread
03_sabr -> 04_hull_white_1f
03_sabr -> 02_ois_swap
```

## 設計上の注意点

SABRは、CMS評価のためだけの部品ではありません。

同じスマイル補間、密度計算、分位点計算のロジックは、以下にも利用できます。

```text
スワップション・スマイルの補間
金利分布の推定
ストレスシナリオの作成
将来金利カーブの分位点分析
```

そのため、SABR関連コードは `05_cms_spread` の下には置かず、`03_sabr` または将来的な `03_SABR` 相当の独立領域として管理します。

## 実装時の考え方

9点程度のストライク別ボラティリティから3パラメータを推定する場合、すべての点を完全に通すのではなく、以下を意識します。

- パラメータの安定性
- 価格曲線の単調性・凸性
- 密度が極端に振動しないこと
- ストレスシナリオとして説明しやすいこと

特に密度関数や分位点を利用する場合、ボラティリティ曲線そのものだけでなく、オプション価格曲線としての滑らかさ・裁定整合性も確認対象とします。
