# 乱数生成設計

## 目的

`06_RandomNumber` は、金利モデルやモンテカルロシミュレーションで利用する乱数生成ロジックの設計を整理するためのドキュメント領域です。

現時点では、Hull-White 1F のモンテカルロシミュレーションなどで利用する標準正規乱数生成を中心に扱います。

## 対象範囲

この領域では、以下を整理します。

- 一様乱数の生成方法
- 標準正規乱数への変換方法
- Box-Muller法
- Mersenne Twister
- Latin Hypercube Sampling
- 準乱数の利用可能性
- 乱数シードの管理
- 再現性のあるシミュレーション設計
- モンテカルロ結果の検証方法

## 関連する主なクラス

| クラス | 役割 |
|---|---|
| `clsRandomNormal` | 標準正規乱数を生成するクラス |

## 位置づけ

乱数生成は、特定の金利モデルに閉じた処理ではありません。

Hull-White 1F、将来のモンテカルロ評価、シナリオ生成などで共通利用する可能性があるため、設計上は `common` に近い部品として扱います。

## 依存関係の考え方

乱数生成ロジックは、下流のモデルや商品評価に依存しないようにします。

```text
RandomNumber -> common
```

または、実装上は `common` 配下のクラス・モジュールとして管理し、ドキュメントだけを `docs/06_RandomNumber` に分ける方針も検討します。
