# ロードマップ

このドキュメントは、`VBA-Rates-Models` の開発順序と移行方針を整理するものです。

## フェーズ1：リポジトリ構成の整理

- 分析目的ごとのドキュメントフォルダを準備します。
- モジュール境界と依存関係の方向を明確にします。
- 既存コードを壊さないように、まずは最終的な置き場と設計方針を文書化します。

## フェーズ2：割引カーブ基盤

対象モジュール：`01_discount_curve`  
設計ドキュメント：`docs/01_Discount_Curve/Design.md`

- `clsDiscountCurve` をカーブインターフェースとして整理します。
- `clsOISStepForwardCurve` を安定化します。
- `clsOISZeroLinearCurve` を安定化します。
- カーブ構築ロジックと取引評価ロジックを分離します。
- Hull-Whiteで使う time-based interface を確認します。

```vb
DF_T(T)
ForwardRate_T(T1, T2)
InstantaneousForward(T)
```

## フェーズ3：OISスワップ評価

対象モジュール：`02_ois_swap`

- OISスワップの商品条件とキャッシュフロー生成を、カーブクラスの外に出します。
- 固定脚PV、変動脚PV、NPV、パーレートを実装・検証します。
- 符号規約を確認します。

```text
PAYER    : FloatingLegPV - FixedLegPV
RECEIVER : FixedLegPV - FloatingLegPV
```

## フェーズ4：SABRモデル

対象モジュール：`03_sabr`

- まずは `beta = 0` の Normal SABR を実装対象とします。
- `alpha`、`rho`、`nu` のパラメータ検証を追加します。
- ストライク別ボラティリティからスマイルをフィットします。
- 必要に応じて価格曲線の平滑化を行います。
- 密度計算、ストライクから分位点への変換、分位点からストライクへの逆算を追加します。

## フェーズ5：1ファクター Hull-White モデル

対象モジュール：`04_hull_white_1f`

- モデル本体のロジックをExcelシート入出力から分離します。
- 割引カーブは time-based interface 経由で利用します。
- 初期キャリブレーション範囲は以下とします。
  - 平均回帰 `a` は外部から固定値として与える。
  - ボラティリティ `sigma` をATM Normal Swaption Volatilityへフィットする。
- 将来時点の短期金利ファクターと将来金利カーブをシミュレーションします。
- リスク管理用に、分位点カーブやストレスカーブを出力します。

## フェーズ6：CMSスプレッド評価

対象モジュール：`05_cms_spread`

- CMS評価が本格化するまでは、ATMスワップション・ボラティリティ処理を中心に整理します。
- 将来的に以下を追加します。
  - CMSレッグ表現
  - CMSスプレッドレッグ表現
  - convexity adjustment ロジック
  - 割引カーブ、スワップション・ボラティリティ、SABR入力を使った評価フロー

## コミット方針

目的ごとに小さくコミットします。

推奨するコミット順序は以下です。

```text
1. ドキュメント構成の整理
2. common部品の移動
3. 割引カーブ関連ファイルの移動
4. OISスワップ関連ファイルの移動
5. Hull-White関連ファイルの移動
6. SABR関連ファイルの追加
7. CMSスプレッド関連ファイルの追加
8. Excel/VBAへのインポート確認後に内部参照を整理
```

ファイル移動とロジック修正は、原則として同じコミットに混ぜない方針とします。
