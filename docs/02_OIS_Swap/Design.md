# OISスワップ評価設計

## 目的

`02_OIS_Swap` は、OISスワップの商品表現、キャッシュフロー生成、評価ロジックを扱うドキュメント領域です。

OISスワップ評価では割引カーブを利用しますが、割引カーブ構築そのものとは責務を分けて管理します。

## 役割

このモジュールの主な役割は以下のとおりです。

- OISスワップの商品条件を保持する。
- 固定脚・変動脚のスケジュールを生成する。
- 固定脚PVを計算する。
- 変動脚PVを計算する。
- PAYER / RECEIVER の符号規約に基づいてNPVを計算する。
- パーレートを計算する。
- Excelで確認しやすいように、キャッシュフロー表を出力する。

## 主なクラス

| クラス | 役割 |
|---|---|
| `clsOISSwap` | OISスワップの商品条件と評価を扱うクラス |
| `clsOISLeg` | 将来的に脚単位の処理を分離する場合の候補クラス |
| `clsCashflow` | 将来的にキャッシュフロー単位の処理を分離する場合の候補クラス |

## 符号規約

固定脚PVおよび変動脚PVは、脚単体のPVとして正値で扱います。

NPVは、PAYER / RECEIVER に応じて以下のように計算します。

```text
PAYER    = FloatingLegPV - FixedLegPV
RECEIVER = FixedLegPV - FloatingLegPV
```

パーレートは、PAYER / RECEIVER に依存しません。

## 依存関係のルール

許容する依存関係：

```text
02_ois_swap -> 01_discount_curve
02_ois_swap -> common
```

避ける依存関係：

```text
02_ois_swap -> 04_hull_white_1f
02_ois_swap -> 05_cms_spread
```

## 設計上の注意点

OISカーブのブートストラップで、OISスワップのパーレート計算に近い処理を一時的に使うことがあります。

ただし、長期的には以下を分離します。

```text
割引カーブ構築
商品条件・キャッシュフロー生成
商品評価
```

カーブクラスに商品評価ロジックを抱え込みすぎると、SABR、Hull-White、CMSスプレッド評価へ拡張するときに依存関係が複雑になります。

そのため、`02_OIS_Swap` は「OISスワップという商品の条件・キャッシュフロー・評価」を扱う領域として管理し、割引カーブそのものの構築は `01_Discount_Curve` 側に残します。
