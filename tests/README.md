# tests

Test cases and validation notes should be organized by module.

```text
tests/
├─ 01_discount_curve/
├─ 02_ois_swap/
├─ 03_sabr/
├─ 04_hull_white_1f/
└─ 05_cms_spread/
```

For VBA, tests may initially be documented as repeatable Excel checks, sample input/output tables, or small test macros.
